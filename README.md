# 🛑 AjjKiProblem

**AjjKiProblem** is a community-driven platform designed to help people **share real problems, prove their existence, connect with others**, and **collaboratively work toward solutions**.

This platform is not only about reporting issues —  
it is about **human connection, emotional support, shared responsibility, and collective problem-solving**.

---

## 🌱 Why AjjKiProblem?

In real life, many people face problems such as:
- College or university issues
- Infrastructure or facility problems
- Administrative delays
- Personal or social challenges  

But often:
- They don’t know **where to share**
- They feel **alone or unheard**
- There is **no proof-based visibility**
- People with similar problems **never find each other**

**AjjKiProblem exists to solve this gap.**

---

## 🎯 What Problems Does It Solve?

✔ Provides a **safe space** to report genuine problems  
✔ Allows uploading **proof** (image / video / audio / document)  
✔ Encourages **solution-oriented thinking**, not just complaints  
✔ Connects people facing **similar issues**  
✔ Supports **anonymous sharing** when needed  
✔ Builds **communities around causes** using pages  
✔ Helps people share **problems, feelings, and support**

---

## 🤝 Human Connection & Collaboration (Core Idea)

Imagine this situation:

> Two people are facing the same problem,  
> but they don’t know each other and no one around them understands.

With **AjjKiProblem**:
- One person posts the problem
- Another person finds it through search or tags
- If user info is shared, they can **connect directly**
- Both can **collaborate, share skills, and support each other**
- Pages help **bring more people together** for the same issue

This platform helps people:
- Feel **less alone**
- Share not just problems, but **emotions**
- Turn individual struggles into **collective strength**

---

## 🛠️ Key Features

### 🔹 Problem Reporting
- Write a clear problem description
- Add related keywords / tags
- Upload proof (image, video, audio, document)

### 🔹 Suggestions & Extra Thoughts
- Suggest solutions or improvements
- Share ideas, context, or emotional thoughts

### 🔹 Optional User Information
- Post **anonymously**
- Or share name, email, mobile & photo to connect with others

### 🔹 Pages System
- Individual pages
- Organization / University pages
- User-created verified pages
- Each page maintains its own problem list

### 🔹 Interaction & Discovery
- Like problems to show priority
- Comment and discuss
- Global search (pages, problems, tags)
- Sort and filter problems

---

## 📖 How to Use (User Guide)

### Step 1️⃣ – Choose a Page
- Select an existing page  
  (Individual / University / Organization)
- Or create a new page

### Step 2️⃣ – Post a Problem
- Describe the problem clearly
- Add keywords (tags)
- Upload proof to show authenticity

### Step 3️⃣ – Add Suggestions
- Share ideas or solutions
- Upload supporting files if required

### Step 4️⃣ – User Details (Optional)
- Stay anonymous  
**OR**
- Share your details to collaborate

### Step 5️⃣ – Explore & Connect
- Like problems
- Comment and discuss
- Search similar issues
- Connect with people facing the same problem

## 🧠 Technical Overview

### Tech Stack
- **Frontend & Backend:** Streamlit (Python)
- **Database:** JSON-based local storage
- **File Storage:** Local file system (can be extended to Google Drive)
- **Deployment:** Streamlit Cloud / Replit (Free)
